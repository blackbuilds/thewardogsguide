WARDOGS Patch 0.11 Notes — Server Browser Split and Sep 14 Maintenance

TL;DR: BULKHEAD scheduled about one hour of downtime on Monday 14 Sep 2026 (01:00 PDT / 08:00 UTC) to ship Patch 0.11. The patch splits the server browser into Community and Official, adds Community text search and persistent server IDs, and notes extra Asia capacity plus cash-exploit and GPU-crash fixes. A 5% end-of-match cash bonus on Community servers runs for one week after the patch. Source: Steam news — Scheduled Maintenance & Patch 0.11.

This page is a dated digest, not a full copy of the Steam post. When a later patch lands, we will add a new dated section rather than overwrite this one.

Maintenance window (as announced)

Region Local time 14 Sep 2026

Steam said the take-down is about one hour. If join or queue errors spike around that window, start on Servers down rather than reinstalling.

What 0.11 changes (Steam notes, paraphrased)

Server browser - Front end splits into two browsers: Community and Official. - Official browser drops extra filters (Steam: no official modified modes yet). - Community browser: more reliable filters, text search, Show Empty/Full on the quick bar. - Community server IDs persist across map changes and restarts; IDs are longer. - Host button points to the correct place. - Server names: alphabetical ignoring special characters/numbers; no more than one space in a row.

Other fixes named in the same post - Various cash exploits fixed. - More GPU crashes addressed. - Increased server capacity in Asia.

One-week Community bonus - Community servers offer a 5% end-of-match cash bonus for the next week (Steam wording). Economy process still lives on Economy.

Not in 0.11 (Steam: still in the pipeline)

Steam listed these as not ready with this maintenance: community server favouriting, tiered priority queues, MOTD prompt, improved warmup, AFK kicking during seeding disable, team-switching controls.

Economy abuse (Steam stance, this post)

The same announcement describes penalties for cash-exploit abuse (timed ban + cash/XP reset), for content that tutorials exploits (permanent ban), and for XP-farming servers (permanent ban). This page does not add extra rules. Official text: the Steam news post linked above.
