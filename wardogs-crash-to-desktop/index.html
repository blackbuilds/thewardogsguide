TL;DR: This page is for crash to desktop (CTD) intent on WARDOGS Steam Early Access — on-start CTD, mid-match / mid-game CTD, and after alt-tab — without inventing FIXED stamps or VRAM numbers. Parent hub remains Crashing / Won’t Launch (Elytra). Fork first: instant desktop before menu vs exit during a match vs focus-loss crash. Collect crashlog / dump only from public leads (else). Highest-yield locals: overlays, fullscreen exclusive, shader first-boot hitch vs true CTD. Suspected VRAM pressure → link Best Settings / Stuttering — no invented VRAM figures. Store anti-cheat is Elytra (not EAC as current). Silent “won’t launch” without a dump → Won’t Launch. Black frame without exit → Black Screen.

Last checked 2026-09-21 (Early Access).

Collect checklist

  1. Screenshot the Crash Reporter / last on-screen line.
  2. Note timing: on-start / mid-match / after alt-Tab / during shader stall.
  3. Copy last 30–50 lines of Wardogs.log if present.
  4. Note GPU + driver + whether overlays were on.
  5. Note whether friends on the same server also dropped.
  6. Then run the ladder — evidence before reinstall loops.

VRAM pressure — link out, don’t invent numbers

Players often describe mid-match CTD after long fights, high texture presets, or when recording overlays add memory pressure. That may be VRAM-related on some hardware — we do not publish invented “needs X GB” or “+Y% VRAM free” claims.

If you suspect… Do Don’t
CTD only in dense fights / high presets Open Best Settings — cut expensive families one-by-one Invent a VRAM requirement table
Hitch then CTD Stuttering / FPS for hitch; return here if process exits Blame “tick rate” for a local dump
CTD only with ShadowPlay/OBS Disable recording overlay; retest Keep recording while “testing stability”

FAQ

Q: WARDOGS crash to desktop — where do I start?
A: Fork timing: on-start vs mid-match vs after alt-tab. Then overlays → verify → Elytra if launch/AC class → display mode A/B. Capture log/dump if present.

Q: Is crash on start the same as won’t launch?
A: Overlap exists. If you get a Crash Reporter / dump, stay on this CTD spoke + Crashing. If Steam goes Idle with no reporter, start at Won’t Launch.

Q: WARDOGS crashing mid game — GPU or servers?
A: If only you drop with a local dump, lean local (overlays / GPU / settings). If the whole lobby dies with auth/timeout text, check Is Down / Servers once before driver surgery.

Q: Where is the crashlog / memory dump?
A: Community pastes cite %LOCALAPPDATA%\Wardogs\Saved\Logs\Wardogs.log and Temp PACKER_….dmp. Confirm on your disk. No official Bulkhead path catalog claimed here.

Q: Is a long “Compiling Shaders” a crash to desktop?
A: Not while the process is alive. Wait once. If it always exits with a reporter at the same point, treat as CTD and continue the ladder + stutter-page cache leads.

Q: Can launch options stop CTD?
A: Maybe as a lab after overlays/verify — one flag (-windowed or -dx11). Full rules → Launch Options. Not a substitute for Elytra on WD-L0… launches.

Q: How much VRAM do I need?
A: Not invented here. If fights CTD on high presets, use Best Settings and Stuttering — cut families one-by-one and stamp your own results.

Q: Does WARDOGS use Elytra or EAC for crash fixes?
A: Store tags Elytra. Team17 Assist troubleshooting also points at Elytra Repair. Keep Elytra-first.

Q: Black screen without desktop return?
A: Black Screen. Return here only when the process actually exits to desktop.
