How to read a WARDOGS error dialog

Treat the dialog like a form, not a meme code.

UI region What to capture Why
Title line e.g. JOIN TIMEDOUT, FAILED TO JOIN, ACCESS DENIED Same number can sit under different titles in community reports — quote yours
ERROR CODE: Exact digits / WD- string Hub table key
Body paragraph Full sentence(s) Distinguishes queue-full vs timeout vs ban-style
Extra fields Reason:, Time Left: Ban-style vs soft auth
Timestamp Local time + region selected Support / Hotfix correlation
Screenshot Full client window if possible Cropping hides context

Dialog anatomy checklist

  1. Do not close until you screenshot.
  2. Note Server Browser region + server name if join-related.
  3. Note whether friends in-region can play (widespread vs local).
  4. Confirm Steam finished any WARDOGS download (Hotfix #1 forced restarts Sep 10 2026).
  5. Only then follow the matching spoke below.

Differentiation matrix (same “can’t play” feeling, different codes)

If the dialog mainly says… Public code lead First spoke Classic mistake

Widespread vs local (hub decision tree)

See error dialog → screenshot full text
  → Are many players failing now (Steam discussions / X @WARDOGS / Discord / friends)?
        YES → Install latest client → wait / follow Hotfix queue steps
              → Spoke: ../wardogs-servers-down/ (and 1628505091 if timeout)
        NO  → Friends in your region play fine?
               YES → Local path: network test (hotspot), verify files, overlays/Elytra if launch
                     → Timeout: ../wardogs-error-1628505091/
                     → Won’t launch: ../wardogs-crashing/
               NO  → Still treat as possible regional service issue first

Boundary cases

Edge Hub reading
Ban fields present Appeal path — do not “wait for servers” forever
Timeout after healthy queue exit Timeout spoke (handshake), not only Servers
Auth text + crash dump both present Status check once, then Crash if dump dominates
Pre-EA calendar screenshots Ignore as current status
Stale ~70/100 server counts + timeout Timeout spoke stale-slot notes

Launch Stability Hotfix #1 (context, not a forever fix)

Intended to address unable to join, unexpected kicks, extended login queues. Press (mp1st) noted a ~200+ MB download and possible further server restarts. Thread replies immediately reported Access Denied / auth failed / WD-LO14-c70b81e405df.

Elytra note (store anti-cheat)

Steam store feature tag (page capture 2026-09-13): Uses Kernel Level Anti-Cheat Elytra. Prior “use EAC repair” wording is outdated for the store tag. Community repair paths (ccstartup / AxeeTech / LagoFast) cite an Elytra folder helper (Elytra.exe / Elytra-Setup.exe → Repair) and log %LOCALAPPDATA%\Wardogs\ElytraLauncher.log — treat as public lead for folder/UI (confirm on disk). Join/auth codes are usually not solved by AC repair during a global outage.

FAQ

Q: Where do I start if I only have a number?
A: Match the table row, screenshot the full dialog, then open the deep link. Numbers without body text are ambiguous.

Q: Is 1628505091 a ban?
A: Public guides (Nerdschalk) say the timeout message alone is not proof of a ban. See ../wardogs-error-1628505091/.

Q: Queue full vs timed out — which is it?
A: 1147405316 public text centers on queue full; 1628505091 on connect timeout. LagoFast also lists Access Denied as a separate check. Quote your dialog.

Q: Access Denied after Hotfix #1 — am I banned?
A: Only if the dialog explicitly shows cheating/permanent ban wording (1147405307-style). Steam Hotfix replies (paraphrased) reported Access Denied / “failed to authenticate online services” without ban fields — use Servers spoke.

Q: What is 1147405308?
A: Bisect describes Failed to Authenticate With Online Services; launch-day reports were often everyone-at-once. current scope → Servers.

Q: What did community managers say during the queue?
A: Bisect quotes CM LOSSY: thousands in login queue slowly filtering in; some players put to the back; response larger than Beta. Ops context, not a code glossary.

Q: What is WD-LO14?
A: Appears in launch-failure reports with hex suffixes (Steam example WD-LO14-c70b81e405df); third parties use WD-L014. Official meaning — triage on Crash with Elytra repair path.

Q: Should I use a VPN?
A: As a diagnostic comparison at most (Nerdschalk-style isolation), not a verified cure. Prefer hotspot test + status check. Do not claim VPN bypasses Valve rate limits (PC Gamer CEO context is press-reported only).

Q: Does Elytra replace Easy Anti-Cheat?
A: Store tag is Elytra. Don’t follow outdated EAC-as-current repair posts blindly — Crash page owns AC identify.

Q: How bad was launch concurrency?
A: PC Gamer: over 300,000 peak + top seller. Secondary public SteamDB cites ~337k–338k. Use as historical load context, not a live “down” badge.

Q: Server shows open slots but I still get 1628505091 — broken install?
A: Not necessarily. LagoFast community reports noted stale counts (around 70/100) still returning Full / Failed / timeout during launch stress. Refresh once, try clearer capacity, or wait if every server fails — then Timeout spoke.

Q: Where do overlays and ElytraLauncher.log fit?
A: Only on the Crash spoke after you have ruled out auth/queue. Store anti-cheat is Elytra; community log path %LOCALAPPDATA%\Wardogs\ElytraLauncher.log (AxeeTech public lead) can distinguish download vs InstallModule failures.

Q: Will this page say FIXED?
A: No. This page updates when patches land. Hotfix #1 is historical process context.
