Error 1147405308 — auth spillover, not a GPU guide

Public third-party framing (Bisect, Sep 10 2026) maps 1147405308 to Failed to Authenticate With Online Services. Launch-day writeups treated it as often service-wide. That is a service-path lead, not proof of a bad GPU driver.

Field Status
Exact EA dialog text public lead — Bisect + Steam Hotfix #1 replies: “Failed to Authenticate With Online Services” / “failed to authenticate online services” (confirm your screenshot)
Default triage Status healthy? → Servers hub. Only then local ladder
Verified local “fix” list None published as confirmed here — do not copy booster VPNs

Rule: If many players show the same auth code right now, do not start overlay/GPU surgery. Open the Servers hub first.

EXCEPTION_ACCESS_VIOLATION and similar

Closed-test community writeups (Aug 2026) document launch crashes with:

Unhandled Exception: EXCEPTION_ACCESS_VIOLATION

involving modules such as user32, ntdll, win32u, and WardogsClient_Win64_Shipping — game never reaches main menu. Those guides often still say “Easy Anti-Cheat”; for EA store tag, swap AC repair to Elytra identify/repair instead.

Elytra log branches (community — AxeeTech)

Misleading launcher text can say the anti-cheat module “could not be downloaded” even when the log shows download + verification succeeded and InstallModule failed.

Log shows Branch Don’t
Download connection fails Network / VPN / proxy / firewall Skip to BIOS tweaks
Download + verification OK, then InstallModule failed + Access is denied (os error 5) Local permissions / TEMP access (community) Endless reinstall loops
Failed to open input file after successful download Local file access Blame “slow internet” alone
Other signatures (BSOD / unrelated DLL) Different guide / support paste Force this os-error-5 path

Community repair preference: use the installer Repair option before manually deleting anti-cheat services or drivers. Reinstalling the entire game may not fix TEMP/ACL problems.

Deprecated fork — Easy Anti-Cheat (do not lead with this)

Prior research and closed-test posts lagged toward EAC while the store now tags Elytra. As of 2026-09-13 store tag, do not treat EAC repair as the current primary path. If a residual EasyAntiCheat folder still exists on disk, document it as anomaly — do not assume deleting it is safe or required.

If WARDOGS never reaches the main menu

  1. Confirm Steam actually finishes launch (Running → Stopped timing).
  2. File verify + overlays off + Windows restart.
  3. Elytra identify → repair fork → read ElytraLauncher.log.
  4. Remove stale Playtest install if present (community).
  5. Only then any EA-confirmed launch option.
  6. If the failure is auth text without crash → Servers.

Escalate to Steam / Discord support when: ladder complete, services look healthy, same crash reproduces with screenshot + paste block. Community notes ticket queues can be large during launch week — still bring evidence.

Post-Hotfix #1 crash-adjacent notes

Hotfix #1 targeted join/kick/queue stability (studio). Community replies also mentioned launch/auth failures (WD-LO14-c70b81e405df, Access Denied). If your “crash” is actually an auth dialog with no dump, you are on the wrong page — bounce to Servers / Error hub.

Won’t launch / wont launch on Steam

If Steam shows Running then stops, or the client never reaches the main menu, stay on this page — that is a won’t launch / wont launch class failure, not a join-timeout guide.

  1. Run the symptom matrix and fix ladder above (verify files → overlays → GPU driver → Elytra repair).
  2. If the dialog is WD-LO14 / WD-L014 / Unable to launch, jump to that section.
  3. If the dialog is auth / Access Denied / 1147405308 with no crash dump → Servers.
  4. If JOIN TIMEDOUT / 1628505091 → 1628505091.

Community repair paths are not stamped FIXED here — record what you tried.

FAQ

Q: Does WARDOGS use Easy Anti-Cheat or Elytra?
A: Steam store feature tag as of 2026-09-13 lists Uses Kernel Level Anti-Cheat Elytra. Confirm folder/UI on your install before repair. Do not follow old EAC-only guides as current default — even some access-violation posts still say EAC from closed-test era.

Q: What does error 1147405308 mean?
A: Public lead (Bisect): Failed to Authenticate With Online Services. Triage as auth spillover → Servers before local GPU steps. Confirm the dialog on your screenshot.

Q: What is WD-LO14 / WD-L014?
A: Appears in launch-failure reports (Steam Hotfix example WD-LO14-c70b81e405df; third-party WD-L014 articles). Community ties it to launcher/Elytra init. Official meaning — try verify + Elytra Repair path, not join-timeout fixes.

Q: Will disabling overlays fix crashes?
A: Closed-test community guides list Discord / Steam / NVIDIA / AMD / Game Bar / Afterburner as frequent hooks for access-violation launch crashes. Test one overlay at a time and record results on your setup. Not a universal fix.

Q: The launcher says the anti-cheat module “could not be downloaded” — is my internet broken?
A: Not always. AxeeTech community report: ElytraLauncher.log can show successful download + verification, then InstallModule failed / Access is denied (os error 5). Read the log before changing DNS/VPN.

Q: How do I repair Elytra?
A: Community path: Steam → Manage → Browse local files → Elytra folder → run Elytra.exe or Elytra-Setup.exe → Repair → restart Steam. Confirm EXE / button labels on your disk. Prefer Repair over deleting driver files.

Q: Are any GPU/driver combos “known bad” on EA Day-1?
A: None confirmed on this page yet. List only from dated retests; otherwise “none confirmed.”

Q: Mid-match crash — is that always my PC?
A: Not always. If the whole server dumps players, check Servers. If only you crash with a local dialog, stay on this ladder.

Q: Can I use launch options like -dx11?
A: Only publish options confirmed on the live EA build. Until then we omit launch-option recipes.

Q: Where do settings/FPS go after launch works?
A: Best WARDOGS Settings. No invented FPS% on this crash page.

Q: Where is the full error code table?
A: Error Codes Hub.

Q: WARDOGS black screen / blackscreen on launch — what first?
A: Treat black screen / blackscreen as a launch-class failure: file verify → overlays off (one at a time) → GPU driver → Elytra identify/repair → read ElytraLauncher.log. Capture exact on-screen text before chasing “shader fix” blogs. If the process stays open but only hitch-stutters, continue on Best Settings. No invented FIXED stamp.

Q: WARDOGS won’t launch / wont launch on Steam — where do I start?
A: Use the symptom matrix: never starts / before menu / WD-LO14 vs auth-only codes. Default local path is verify + overlays + Elytra repair (not old EAC folder deletes). Auth / Access Denied / 1147405308 without a crash dump → Servers.

Q: WARDOGS stuttering — is that this crash page?
A: If the client launches and only stuttering / FPS hitching remains, go to Best Settings. Stay here when stutter ends in a crash dialog, black screen exit, or won’t-launch loop.

Q: Mid-game crash / mid-match crash — always my PC?
A: Not always. If the whole server dumps players, check Servers. If only you crash with a local dialog, stay on this ladder (overlays / GPU / Elytra). Same rule as the mid-match FAQ above.

Q: WD-L014 / WD-LO14 Unable to launch — exact spelling?
A: Steam Hotfix community example used WD-LO14-…; third-party posts also write WD-L014. Treat them as the same launcher/AC-init cluster until proven otherwise. Community path: verify files → Elytra Repair → log read. Official meaning stays unverified — do not invent.

Q: AMD GPU — any special WARDOGS crash steps?
A: Same ladder as other GPUs. Community often cites AMD overlay (Adrenalin) alongside Discord/Steam/GeForce overlays for access-violation class launch crashes — disable overlay, keep the driver, retest. No AMD-specific FIXED claim published here.

Q: Does WARDOGS still use Easy Anti-Cheat (EAC)?
A: Store feature tag as of 2026-09-13 is Elytra (kernel-level). Keep Elytra-first. Residual EasyAntiCheat folders, if any, are anomalies to document — not the default repair path.
