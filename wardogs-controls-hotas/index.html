Controller Day-1 checklist

  1. Plug one pad only; quit RGB/virtual joystick tools.
  2. Launch WARDOGS; note whether prompts show glyphs.
  3. Open Controls — document which actions are remappable.
  4. If native remap is shallow, enable Steam Input and retest one template (PixelNitro: gyro-on-ADS optional).
  5. Test infantry ADS + vehicle enter + heli collective separately.
  6. If the game soft-locks on device switch, note build and file under Crash if needed.

Title/body rule: say partial controller support and limited remapping. Do not write “full controller support” or imply console parity.

HOTAS for helicopters: axis path (not “full support” marketing)

allthings HOTAS (Sep 10, 2026) + Games Fuze: WARDOGS treats sticks as analog devices. Path: Settings → Gamepad → HOTAS sub-tab → Enable HOTAS = Enabled, then bind roll, pitch, yaw, collective. Game swaps to stick in heli seat and back to KBM on foot (reported).

Field Public lead Notes
Axis model Deflection = continuous rotation rate until centered (not attitude hold) Feel test
Deadzones (third-party working values) Roll 0.02, Pitch 0.03 (allthings) Hardware-dependent
Pitch/Roll sensitivity Leave near 1.0; lowering caps max rotation rate Don’t gut emergency authority
Collective Match full throttle travel to full collective gauge Tune by feel
Extra buttons Bind from pilot seat in normal Controls (not main menu) Interact, flares, PTT, vendor
Other bugs Axis sticks after remap; slow freelook; Lakota assists may not apply on stick allthings known-problems table

HOTAS exclusivity / session warning

Community heli guides report that rebinding an air axis/key can remove the same key from on-foot (exclusive binds), and HOTAS maps may reset between sessions. Treat that as a session tax — test Interact / Build after any heli remap; budget 2–3 minutes to rebind at session start.

Never claim full HOTAS support from query interest alone.

Binds will not save: Day-1 troubleshooting

Use a known bug only after reproducing it on EA. Beta Steam Support mouse-button titles and “delete GameUserSettings.ini” tips are leads, not Day-1 facts. HOTAS non-persistence is the strongest dated community report (allthings).

Safe triage order (no reckless file deletes)

  1. Confirm latest Steam client update for WARDOGS (Hotfix era restarts matter).
  2. Re-apply one bind; fully exit to desktop; relaunch; check persistence.
  3. Disable overlays (see Settings / Crash).
  4. Test another user Windows account only if you suspect profile corruption.
  5. Config-file surgery (%LOCALAPPDATA%\… paths from third-party guides) stays — backup first if you ever try it; this page will not instruct destructive deletes as verified.

FAQ

Q: Does WARDOGS have partial controller support on PC Steam EA?
A: Research narrative is partial / limited remapping / Steam Input. Bisect publishes layouts; allthings notes heli remap limits. Official in-client support wording is omitted until we screenshot the store / Controls chrome. Forbid “full official controller support” until live menus prove deep remapping.

Q: Does it support HOTAS, and what does “support” mean?
A: Dated guides document Settings → Gamepad → HOTAS → Enable HOTAS and axis binding for helicopters. Expect possible session remaps. That is not polished “full HOTAS support” marketing.

Q: How are infantry and vehicle/air controls rebound?
A: Separate keybind groups (Bisect). HOTAS axes under Gamepad → HOTAS. Watch for exclusive binds that steal on-foot keys.

Q: Are there known EA Day-1 keybind bugs, including binds that do not save?
A: HOTAS non-persistence is a strong community lead (allthings). Other beta/Support leads exist; publish bug rows only after EA reproduction.

Q: What are the best starter binds for building and ADS?
A: Keep Interact reachable for towers (F lead). Building rotate/snap leads from Bisect. ADS default RMB until you screenshot.

Q: Which default KBM controls are essential for a first match?
A: WASD, fire/ADS, Reload, Interact F, Map M, Inventory Tab — then verify on your build. Not a scraped full Bisect mirror.

Q: Can Steam Input improve controller play?
A: Yes when native remap is shallow — PixelNitro/allthings leads. Properties → Controller path and any working template before recommending one.

Q: My binds crashed the game / WARDOGS won’t launch after remapping
A: Stop changing binds; follow Crashing (Elytra-aware). Then return here.

Q: Where do I learn tower Interact binds?
A: Interact defaults here + tower flow on Towers + first match on How to Play.

Q: Deadzone values for HOTAS?
A: allthings working leads Roll 0.02 / Pitch 0.03 — hardware-dependent. Tune until true zero at rest.
