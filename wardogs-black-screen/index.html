TL;DR: This page is for black screen / blackscreen / stuck at startup on Steam Early Access — the process starts (or Steam says Running) but you never reach a usable menu. It is distinct from mid-match crash and from auth/queue codes like 1147405308. Fork first: music-but-black (display / window / overlay) vs hard crash (dump / instant desktop). Store anti-cheat is Elytra (not EAC as current). Safe tests: overlays off one-at-a-time → windowed launch option ( flags on Launch Options) → file verify → GPU driver sanity → Elytra identify/repair if launch dies at AC init. Shader-compile stalls that later recover → patience + stutter notes; process exit → Crash ladder. No invented FIXED stamps.

Last checked 2026-09-16 (Early Access).

Windowed / display notes

Public guides (2UpSkill, LagoFast FAQ) cite -windowed / borderless-style tests when music continues on a black frame. Treat flags as community lab tools, not studio-verified miracles:

  • Put one option in Launch Options, launch once, record result.
  • Full catalog + “may no-op” labels → WARDOGS Steam Launch Options.
  • After you recover a visible window, set a stable display mode in-game Settings (labels) before removing the temporary flag.

FAQ

Q: WARDOGS black screen on launch — where do I start?
A: Decide music-but-black vs hard crash. Then overlays → -windowed test → verify files → GPU driver → Elytra repair. Auth text → auth spoke, not this ladder.

Q: Is black screen the same as mid-game crash?
A: No. Mid-match exits after you already played belong on Crashing. This page is startup / display init / shader-at-boot.

Q: Should I repair Easy Anti-Cheat?
A: Not as the current default. Store tags Elytra. Use Elytra identify/repair community path; treat leftover EAC folders.

Q: Which Steam launch options fix black screen?
A: Community leads often start with -windowed; -dx11 appears as an isolated lab flag. All flags need and may no-op — full lab on Launch Options. Never dump a pile of undocumented miracles.

Q: How long should I wait on “Compiling Shaders”?
A: LagoFast-class public lead: first compile can look stuck for a long stretch yet continue. If the process is alive and disk/GPU active, wait once. If it always crashes at the same point, switch to Crash + cache cleanup leads.

Q: Overlays keep breaking the picture — which one?
A: Disable one at a time and re-enable after success. Discord and vendor overlays are the highest-cited locals; your PC may differ.

Q: I fixed the black screen but now hitch in matches — next page?
A: Stuttering or Low FPS for symptom triage; Best Settings for FPS-vs-clarity slider goals. No invented FPS%.

Q: Steam says Running then stops with WD-LO14.
A: That is Unable to launch / AC init class → WD-L014 and Crash Elytra section.

Q: Could this be servers down?
A: Only if you actually receive auth/queue dialogs. Pure black local window with no online-services text stays on this page; status habit still useful once via Is Down.

Q: Does HDR or multi-monitor cause WARDOGS black screen?
A: Undocumented as official. Treat as A/B: windowed on primary display, then toggle HDR/Auto-HDR once. Document results; don’t invent a universal rule.

Q: I hear compiling shaders but see black — wait or kill?
A: If the process is alive and disk/GPU busy, wait once (LagoFast-class patience lead). If it repeatedly dies at the same percent with a crash reporter, switch to Crash + shader-cache leads — don’t infinite-wait a hard crash.
